# Procurement App

An Odoo 19 module for managing the full procurement workflow:

- **Material Requests** — Create and approve material requests
- **RFQs (Request for Quotations)** — Send RFQs to multiple suppliers
- **Supplier Quotes** — Track and compare supplier quotes
- **Purchase Orders** — Manage approved purchase orders
- **Purchase Invoices** — Handle purchase invoices
- **GRVs (Goods Received Vouchers)** — Record goods received

## Approval Workflow
Every document follows: `Draft → Submit for Approval → Approved/Rejected → Confirm → Done`

## Installation
Place the `material_requisition` folder in your Odoo addons path and install via Apps menu.
